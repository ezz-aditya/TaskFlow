# TaskFlow – Task Management Application

TaskFlow is a full-stack task management application designed to help users organize, manage, and track their tasks efficiently.

## 🚀 Live Demo
- **Frontend:** https://task-flow-gules-iota.vercel.app/
- **GitHub Repository:** https://github.com/ezz-aditya/TaskFlow

## ✨ Features
- User-friendly interface
- User authentication
- Create, view, update, and delete tasks
- Task management dashboard
- Responsive design

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Vercel

## ⚙️ Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/ezz-aditya/TaskFlow.git
cd TaskFlow
```

### 2. Setup Backend
```bash
cd taskflow/server
npm install
```

Create a `.env` file in the server directory:

```env
MONGO_URI=your_mongodb_connection_string
```

Start the backend:

```bash
npm start
```

### 3. Setup Frontend
Open another terminal:

```bash
cd taskflow/client
npm install
npm run dev
```
